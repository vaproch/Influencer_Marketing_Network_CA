# Raw network data

The simulation scripts download the SNAP ego-Twitter edge list
(`twitter_combined.txt.gz`, about 44 MB) into this folder on first use and cache
the cleaned graph as `twitter_graph.pt`. Neither file is tracked in git.

Source: <https://snap.stanford.edu/data/ego-Twitter.html>
(Leskovec & McAuley, 2012; Leskovec & Krevl, 2014).
